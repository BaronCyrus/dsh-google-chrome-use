# v0.1.0：让 DeepSeek Harness 用上 Google Chrome

第一版。模型可以用你电脑上的 Chrome 打开网页、读内容、点击、填表、上传文件和截图，底层是 Chrome 官方的 chrome-devtools-mcp。

- **两种 Chrome**：默认用一个独立配置，登录状态会保留；也可以连接你正在用的 Chrome（需要 Chrome 144 或更新版本），不用装扩展。
- **按需加载**：没用到浏览器的会话只多一个工具定义，调用 `chrome_use` 后浏览器工具才出现。
- **连接引导**：连接你的 Chrome 时，插件会打开 Chrome 的设置页，并说明 macOS 的文件夹权限怎么开。
- **按网站询问**：在你的 Chrome 里第一次打开某个网站时，DSH 会先询问。完全访问模式下不询问。
- **隐私默认值**：关闭使用统计和更新检查，遮蔽敏感请求头，上传和保存文件默认只限系统临时目录。

连接你的 Chrome 后，模型会收到所有标签页的标题和网址，这些内容会发给你配置的模型服务。使用前请读 [SECURITY.md](https://github.com/BaronCyrus/dsh-google-chrome-use/blob/main/SECURITY.md)。

验证：macOS 上，在桌面版 0.2.1-rc.3 里用真实模型跑通了独立 Chrome 和连接正在使用的 Chrome，在 Web 版测了按网站询问的允许和拒绝，并在 0.1.5-rc.2、0.2.1-rc.3、0.2.1-rc.5 上跑过脚本化的完整流程，其中也包括从 npm 安装这个版本。Windows 目前只在 GitHub Actions 上用无头 Chrome 跑过单元测试和脚本化的完整流程。默认的带窗口模式、实机的桌面版，以及连接正在使用的 Chrome 时的勾选和允许弹窗，都还没有在 Windows 上试过。

在 DSH 插件页添加 `dsh-google-chrome-use@0.1.0`，然后完全退出并重新打开 DSH。
