# v0.2.0：在设置里更新插件

这一版开始，插件可以在 DSH 的设置页里更新，不用再卸载重装。

- **设置 → Chrome Use**：显示正在运行的版本。打开这一页时会去 npm 查最新版本，有新版本时点「更新插件」，再完全退出并重新打开 DSH。插件不会在后台自己更新。
- **更新走 DSH 自带的 pnpm**，遵守发布冷却策略。安装源还没同步、连不上或者被冷却期挡住时，页面会说明原因。

验证：在 DSH 0.2.1-rc.5 的临时 Web profile 里打开这一页并点更新，通过真实的 npm 和桌面版自带的 pnpm 装上了新版本；另外用桌面版的程序和 pnpm 单独跑过同样的更新。桌面版窗口里的这一页还没有实际操作过。GitHub Actions 的 Windows 机器现在也用带窗口的 Chrome 跑冒烟测试和 DSH 内的完整流程，屏幕截图里能看到 Chrome 窗口和填好的表单。Windows 实机的桌面版，以及连接正在使用的 Chrome 时的勾选和允许弹窗，都还没有试过。

0.1.0 没有这一页，所以这次要手动升级：在 DSH 插件页卸载，再添加 `dsh-google-chrome-use@0.2.0`，然后完全退出并重新打开 DSH。`cordis.patch.yml` 里的配置行不受影响。
